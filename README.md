## Open Source

### 🔗 deeplink_setup

A Flutter CLI toolkit for generating, configuring, and validating **Android App Links** and **iOS Universal Links**.

- Generate `assetlinks.json` and Apple App Site Association files.
- Configure Android and iOS project settings with backups.
- Validate local configuration and live website files.
- Diagnose differences between origin AASA files and Apple's CDN.
- Run health checks and integrate validation into CI workflows.

**Dart · Flutter Tooling · Deep Linking**
